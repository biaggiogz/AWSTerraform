## How the Streamlit App is Exposed Through ECS + ALB + CloudFront

The Streamlit app is exposed to users through a multi-layered architecture that includes ECS (Elastic Container Service), ALB (Application Load Balancer), and CloudFront. Here's how the traffic flows:

### 1. Container Level (Dockerfile)
- The Dockerfile exposes port 8501 with `EXPOSE 8501`
- The Streamlit app runs with the command `streamlit run dashboard.py --server.port=8501 --server.address=0.0.0.0`
- This makes the app listen on all network interfaces (0.0.0.0) on port 8501

### 2. ECS Level
- The ECS task definition maps the container port 8501 to the host:
```terraform
container_definitions = jsonencode([{
  portMappings = [{
    containerPort = var.container_port, # 8501
    hostPort      = var.container_port, # 8501
    protocol      = "tcp"
  }]
}])
```
- The ECS service is configured to run in public subnets with a security group that allows inbound traffic from the ALB to port 8501:
```terraform
network_configuration {
  subnets         = [aws_subnet.public_subnet1[0].id, aws_subnet.public_subnet2[0].id]
  security_groups = [aws_security_group.streamlit_ecs_sg[0].id]
  assign_public_ip = true
}
```

### 3. ALB Level
- The ALB target group is configured to forward traffic to the ECS service:
```terraform
resource "aws_lb_target_group" "streamlit_tg" {
  port        = 80
  protocol    = "HTTP"
  target_type = "ip"
  vpc_id      = aws_vpc.streamlit_vpc[0].id
  health_check {
    path = "/healthz"
  }
}
```
- The ECS service registers with this target group:
```terraform
load_balancer {
  target_group_arn = aws_lb_target_group.streamlit_tg.arn
  container_name   = "${var.app_name}-container"
  container_port   = var.container_port  # 8501
}
```
- The ALB has HTTP (port 80) and optional HTTPS (port 443) listeners that forward traffic to the target group
- Security groups allow the ALB to receive traffic from the internet and send traffic to the ECS containers on port 8501

### 4. CloudFront Level
- CloudFront distribution is configured as the front-most layer:
```terraform
resource "aws_cloudfront_distribution" "streamlit_distribution" {
  origin {
    domain_name = aws_lb.streamlit_alb.dns_name
    origin_id   = "${var.app_name}-origin"
    
    custom_header {
      name  = var.custom_header_name
      value = var.custom_header_value
    }
    
    custom_origin_config {
      http_port              = 80
      https_port             = 443
      origin_protocol_policy = "http-only"
      origin_ssl_protocols   = ["TLSv1", "TLSv1.1", "TLSv1.2"]
    }
  }
}
```
- CloudFront sends a custom header to the ALB to verify the request is coming from CloudFront
- The ALB has a listener rule that only accepts traffic with this custom header:
```terraform
resource "aws_lb_listener_rule" "deny_rule" {
  action {
    type             = "forward"
    target_group_arn = aws_lb_target_group.streamlit_tg.arn
  }
  condition {
    http_header {
      http_header_name = var.custom_header_name
      values           = [var.custom_header_value]
    }
  }
}
```
- Any direct access to the ALB (bypassing CloudFront) is redirected to the CloudFront URL:
```terraform
resource "aws_lb_listener_rule" "redirect_rule" {
  action {
    type = "redirect"
    redirect {
      host        = aws_cloudfront_distribution.streamlit_distribution.domain_name
      protocol    = "HTTPS"
      status_code = "HTTP_301"
    }
  }
}
```

### Traffic Flow Summary
1. User requests → CloudFront (port 443/HTTPS)
2. CloudFront → ALB (port 80/HTTP with custom header)
3. ALB → ECS Task (port 8501)
4. ECS Task → Streamlit container (port 8501)

This architecture provides:
- Global content delivery via CloudFront's edge locations
- Security through custom headers between CloudFront and ALB
- Load balancing across multiple ECS tasks
- HTTPS termination at CloudFront
- Proper port mapping from the container to the outside world

The key to this setup is the port mapping and security group configurations that allow traffic to flow through each layer while maintaining security.
